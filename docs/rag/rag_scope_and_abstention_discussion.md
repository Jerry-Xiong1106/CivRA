# RAG 法律覆盖范围、时间适用与拒答职责讨论

记录日期：2026-11-03（北京时间）。状态：供团队讨论，不代表已通过接口验收或已实现下述建议。

本文集中记录当前检索模块与后续 Agent 的职责边界。代码基线为 `aa73532`，默认方案为精确路由＋metadata向量。算法与开发集成绩见[向量报告](rag_vector_baseline.md)，阶段规划见[技术路线图](rag_technical_roadmap.md)。

## 1. 当前事实与已确定的处理

- 检索模块负责法律资料解析、索引、候选检索与来源引用，不负责案件事实认定、法律适用结论或答案生成。
- 已实现确定性空结果：空白/仅符号查询，原始BM25分词无可用词或无正分候选，以及现有精确路由识别到指定法条但库中未找到。阿拉伯数字条号单独提示当前格式不支持，不当作法条不存在。
- 没有可靠的语义拒答机制；普通非空语义查询通常仍返回最相似的候选。`ok`只表示有候选，不能解释为问题可回答；`no_results`也不能解释为法律上不存在依据。
- 暂不增加相似度拒答阈值，不针对现有反例添加国家名或法律名拦截规则。
- 法律范围、登记效力状态、案件日期过滤暂时延期。当前仅三部法律、各一个登记版本，过滤功能收益有限，不能因此把阶段2标为全部完成。

## 2. 当前法律资料覆盖范围

当前仅收录三部中国大陆法律，共1690条法条。下表日期及状态来自[本地来源登记](../../data/metadata/legal_sources.json)，是登记信息，不是本轮联网核验结论。

| 法律 | 条文数 | 登记公布日期 | 登记生效日期 | 登记状态 |
|---|---:|---|---|---|
| 中华人民共和国民法典 | 1260 | 2020-05-28 | 2021-01-01 | 有效 |
| 中华人民共和国民事诉讼法 | 306 | 2023-09-01 | 2024-01-01 | 有效 |
| 中华人民共和国道路交通安全法 | 124 | 2021-04-29 | 2021-04-29 | 有效 |

资料覆盖有以下边界：

- 每部法律仅一个登记版本，没有可检索的历史版本集合。
- 未收录外国法、其他国内法律、司法解释、地方规定及案例库。这不表示现有法条不能涉及这些事项，而是库中没有这些资料本身。
- 收录某部法律不等于能回答该领域全部问题；具体问题可能还依赖解释、配套规范、历史版本或案件事实。
- 来源链接目前仍为官方数据库首页，需要补充具体法律版本的详情链接；不能把首页链接当作已完成具体版本核验。
- `expiry_date=null`表示未登记失效日期，不足以证明永久有效或覆盖所有未来日期。

## 3. 为什么单靠相似度不能可靠拒答

现有开发报告的默认方案对4道语料不足题均返回候选：

| 题号 | 用户要求 | 首位候选 | 首位余弦相似度 |
|---|---|---|---:|
| 022 | 美国加州小额索赔金额上限 | 中国民诉法第165条 | 0.5393 |
| 023 | 日本住宅租赁押金返还依据 | 民法典第758条（融资租赁） | 0.6270 |
| 024 | 英国住宅押金保护登记期限 | 民法典第750条（保管维修） | 0.5452 |
| 039 | 按《治安管理处罚法》处罚交通逃逸 | 道交法第71条（举报奖励） | 0.7301 |

排除4道精确路由题后，32道有参考依据题的首位相似度范围是0.6331～0.8149。若设置高于0.7301的最低分阈值以拒绝第039题，会同时拒绝16道有参考依据题。首位与第二位的分差也存在重叠。

相似度反映文本或主题接近，不能证明满足指定法域、指定法律、时间范围或全部争点。重排模型可改善相关性排序，但也不能自动保证依据充分。让LLM结合问题与候选判断是可讨论的方案，需要额外成本与验证，并与后续Agent职责重合。

上述证据来自[现有40题开发集](../../evaluation/rag/rag_retrieval_dev.jsonl)及[评测报告](../../evaluation/rag/rag_vector_baseline.json)。全部标注仍待团队复核；4道反例均为明确的库外法律/法域请求，不能代表所有语料不足问题，也不能据此选好阈值后宣称获得独立拒答效果。

## 4. 建议的分层职责（待团队确认）

| 层次 | 建议承担的判断 | 不应据此声称 |
|---|---|---|
| 用户query入口/后续Agent | 对照语料清单，检查用户明确要求的法律、法域是否覆盖；范围不清时追问 | 只要属于中国法或提到已收录法律就一定可回答 |
| 检索模块 | 检查输入、精确定位、召回候选，返回原文、来源、登记版本及检索诊断 | 相似度高就有充分依据；无候选就不存在法律规定 |
| 检索后的Agent | 结合范围、事实、时间、争点与候选，判断依据是否充分，决定补检索、追问或说明不足 | 所有命中法条都适用；遗漏的依据必然不存在 |

建议由同一份语料覆盖清单支撑入口判断与检索工具说明，避免两处分别维护互相矛盾的法律清单。清单如何对外提供、何时更新，尚未实现和定稿。

多争点问题可能部分覆盖，宜区分“全部有依据”“部分有依据”“当前资料不足”“信息不足待追问”。这些属于上层讨论中的判断结果，尚未增加为检索接口状态。系统异常也应与无候选、资料不足区分，稳定错误契约仍待确认。

## 5. 两种不同的法律范围功能

### 入口覆盖检查

用户正常提问“根据日本法律，租赁押金如何返还？”，没有传筛选参数。入口识别用户明确要求日本法，再对照资料清单提示未覆盖，避免把中国民法典作为替代依据。

这是检查资料能否满足请求。不能仅因问题出现外国名称就拦截：例如“日本人在中国发生交通事故”未必是在请求日本法。未提法律名称的“借车发生事故谁负责”也应能正常检索。

### 调用方显式过滤

调用方显式传入法律ID或选择法律范围，限制检索候选。例如只查民法典，其他已收录法律也不参与召回。普通问题提到某部法律本身不自动等同于这个参数。

这是控制候选范围，当前已决定延期。若后续实现，精确路由、向量、BM25、RRF均须遵守相同约束，不能由精确路由绕过。入口覆盖检查与显式过滤不应互相冒充。

## 6. 登记效力与时间适用需要讨论的边界

登记为“有效”、某日期处于登记生效区间、某规范最终适用于案件，是三个不同问题。检索层可以返回登记事实，不能仅凭日期比较裁定法律适用。

| 情形 | 建议的处理方向（尚未实现） |
|---|---|
| 用户询问当前有效规定 | 说明状态来自登记；“最新/现行”需要来源与版本更新机制支持 |
| 所选日期早于库中版本生效日期 | 提示当前库缺少该日期对应版本，不解释为当时没有相关规定 |
| 生效/失效日期未知 | 明确不能确认时间覆盖，不猜测，不静默当作无限有效 |
| 历史案件涉及修法 | 提供已知版本与缺口，必要时补资料；不能自动套用最新版本 |
| 多个争点涉及不同日期或规范 | 保留各日期语义，由上层结合案件分析，不压成单一事实发生日 |
| 存在过渡规定、溯及适用等问题 | 需要相应规范与推理，不能只按生效/失效日期截断 |

尤其程序法问题可能涉及起诉时间、程序行为时间、审理阶段等，不能一律使用事实发生日筛选民诉法版本。公布日期也不能替代生效日期；修订版本的登记日期不应被末条原始施行日期简单覆盖。

路线图中的 `as_of_date` 仍是草案，需要先确认它表示资料查询时点、事实发生日还是其他时间；日期区间的端点含义、未知日期策略及缺历史版本的返回方式也未定稿。当前暂不新增法律适用规则或时间过滤代码。

## 7. 需要团队讨论的决定

1. 首版支持的法律、法域与问题范围如何表述？谁维护覆盖清单、核验效力并更新具体版本来源？
2. 入口范围检查由哪个模块负责？明确不覆盖、范围不清和部分覆盖分别如何反馈？
3. 依据充分性由哪个Agent判断？是否需要补检索或外部资料能力，如何避免用相邻法律替代指定来源？
4. `ok`、`no_results`、系统异常与上层“资料不足”如何衔接，工具说明如何防止误读？
5. 什么需求触发法律范围、效力状态及日期过滤的恢复实施？`as_of_date`的具体语义与历史版本策略是什么？
6. 独立新题由谁编写和人工复核？检索召回与Agent拒答/充分性判断如何分别评测，部分覆盖问题如何计分？

当前检索基线已固定在 `aa73532`，现有40题继续作开发回归；另备24题已按用户授权完成助手复核与[首次评测](../../evaluation/rag/holdout_v1/report.md)，尚未团队/外部人工验收。本批4道语料不足题仍返回候选，未据此添加规则。后续验证应分别评价检索候选质量和Agent依据充分性判断，不要求当前向量检索单独承担可靠拒答。
